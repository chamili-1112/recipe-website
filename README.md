# 🍽️ Recipe Website

## 📌 Overview

Recipe Website is a web application designed to help users explore, search, and view different recipes with ingredients and preparation steps. The platform provides an easy-to-use interface for discovering cooking ideas and improving the user experience in finding recipes.

## 🚀 Installation & Setup

### Clone Repository

```bash
git clone https://github.com/chamili-1112/recipe-website.git
```

### Navigate to Project Folder

```bash
cd recipe-website
```

### Install Dependencies

```bash
npm install
```

### Run Project

```bash
npm run dev
```

Open in browser:

```bash
http://localhost:5173
```
